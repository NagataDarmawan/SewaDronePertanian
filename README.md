## About

AgroFly is a website concept for an agricultural drone rental service, designed to introduce drone-based solutions for modern farming activities.

The project aims to present agricultural drone rental services through a professional and user-friendly digital platform.

With a modern interface and responsive layout, AgroFly demonstrates how technology can support agricultural businesses and improve the way services are presented online.

## Features

- **Service Presentation** — Introduce agricultural drone rental services.
- **Modern Landing Page** — Present services through a clean and professional interface.
- **Responsive Design** — Adaptable layout for desktop and mobile devices.
- **Service Information** — Display information related to agricultural drone services.
- **Contact Section** — Provide an inquiry channel for potential customers.
- **Interactive Interface** — Smooth interactions and user-friendly navigation.

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

Clone this repository to your local machine.

```bash
git clone https://github.com/NagataDarmawan/SewaDronePertanian.git
```

### 2. Navigate to the Project

Move into the project directory.

```bash
cd SewaDronePertanian
```

### 3. Install Dependencies

Install all required dependencies.

```bash
npm install
```

### 4. Run Development Server

Start the local development server.

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
